甘丹 LINE Helper 隱私權政策

最後更新：2026 年 10 月 14 日

「甘丹 LINE Helper」（以下稱「本工具」）由甘丹設計維護，僅供甘丹設計授權人員處理品牌合作、業配邀約與相關工作通知使用。本政策說明本工具如何存取、使用、保存及分享 Google 使用者資料。

一、存取的 Google 使用者資料

本工具在使用者明確授權後，使用以下唯讀權限：

  • Gmail 唯讀：讀取信件寄件者、主旨、收件時間、郵件內文、摘要、連結及附件檔名，以辨識品牌合作與業配邀約。
  • Google Drive 唯讀：只在信件包含 Google Drive 連結，且該檔案可能是轉寄郵件原始檔時，讀取授權帳號有權存取的相關檔案內容。

本工具不會代替使用者寄信、刪除信件、修改信件、建立或變更 Gmail 標籤，也不會修改或刪除 Google Drive 檔案。

二、資料使用目的

  1. 篩選可能的品牌合作、付費業配、影音合作或團購邀約。
  2. 產生精簡摘要、分類結果與待追蹤狀態。
  3. 將必要的合作摘要或系統健康通知傳送給甘丹設計指定人員。
  4. 排除電子報、一般廣告、展覽通知及其他與合作無關的信件。

本工具不會將 Google 使用者資料用於廣告投放、建立廣告受眾、出售資料或其他與上述目的無關的用途。

三、資料處理與第三方服務

  • 大部分篩選與狀態管理在甘丹設計授權的本機電腦執行。
  • 對於本機規則無法明確判斷的模糊候選信件，本工具可能將寄件者、主旨、最多 500 字的摘要及最多 3,000 字的郵件內文提交至 OpenAI Codex 服務，僅用於判斷是否為合作邀約。
  • 本工具可能透過 LINE Messaging API，將合作信件的主旨、來源、摘要、判定結果及 Gmail 開啟連結傳送給甘丹設計指定人員。
  • 除上述必要處理外，甘丹設計不會將 Google 使用者資料提供給其他第三方，法律要求或維護資訊安全所必須的情況除外。

四、保存方式與期間

本工具可能在授權的本機環境保存 Gmail 郵件 ID、討論串 ID、寄件者、主旨、收件時間、來源信箱、合作摘要、分類、追蹤狀態、通知紀錄、系統健康紀錄，以及必要的 OAuth 授權權杖與應用程式憑證。

完整郵件內文主要在掃描與判定期間暫時處理；本工具的合作狀態檔不保存完整郵件內文。必要紀錄保存至合作追蹤目的完成、授權人員要求刪除，或甘丹設計判定已無業務與法令保存需要為止。

五、資料安全

本工具採用 Google OAuth 2.0，並限制為 Gmail 與 Google Drive 唯讀權限。憑證與權杖不公開、不提交至公開程式碼儲存庫；系統僅允許授權的 Windows 使用者與甘丹設計指定人員存取。

六、停止授權與刪除要求

使用者可隨時透過 Google 帳戶的第三方應用程式連線設定撤銷本工具的存取權。撤銷後，本工具將無法再讀取新的 Google 使用者資料。

如需查詢、修正或刪除本工具保存的相關資料，請透過下方聯絡方式提出要求。已依法或基於必要安全紀錄保存的資料，可能於適用期限屆滿後刪除。

七、Google API 資料政策

本工具對 Google API 所取得資訊的使用與傳輸，將遵守 Google API Services User Data Policy，包括 Limited Use 規定。

八、政策更新

如本工具的功能、資料使用方式或適用規範有重大變更，本政策將同步更新並標示最新日期。
